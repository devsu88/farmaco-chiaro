## Project context: Farmaco Chiaro

- Public surface: FastAPI under `/api/*`, proxied same-origin by Next.js. Routes in `backend/app`, schemas in `backend/app/schemas`.
- Pydantic v2 models are the contract; FastAPI serves OpenAPI at `/openapi.json`.
- Chat responses carry the answer plus cited block IDs; document endpoints return blocks with stable IDs.
- Keep a stable JSON error shape and Italian user-facing messages.
- There is no auth layer and no database today: do not design OAuth, JWT, pagination, or GraphQL without an explicit requirement.
