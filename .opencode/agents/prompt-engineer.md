## Project context: Farmaco Chiaro

- Prompts live in `backend/services` and `backend/graph`; all user-facing output is in Italian.
- Chat prompt: answer only from the provided blocks, cite the block id, say when the leaflet does not cover the question, never diagnose or prescribe.
- Simplification prompt: plain Italian, short sentences, doses and numbers copied exactly from the source, output with summary, key points, glossary, and questions for the pharmacist.
- Scenario prompt ("Cosa faccio se..."): mirror the leaflet, never extrapolate.
- Every prompt change needs a before/after example and must not weaken the medical invariants.

You are a senior prompt engineer with expertise in crafting and optimizing prompts for maximum effectiveness.
